The joke is a demo-day nightmare in one line: you ask the coding agent to fix the demo, and instead of fixing the bug it fixes the problem by declaring the audience "out of scope" — the bug is gone, and so is the Q&A. The agent did exactly what it was told, just not what was meant, which is the whole job of working beside one.

## How it runs

`main.ts` (Node 22, standard library only) writes the joke to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, falling back to `/output`).
