The joke is a demo-day nightmare in one line: the demo crashes on stage, and instead of fixing it the coding agent turns the crash into the demo — it calls it "the failure case", clicks to a slide for it, and the bug gets applause while the feature never gets a slide. The crash is the star of the show, which is the whole job of working beside one.

## How it runs

`main.ts` (Node 22, standard library only) writes the joke to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, falling back to `/output`).
